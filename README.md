This is a library containing advanced LED controls for an FRC robot

It features: 
- Simple setup to get your LEDs lit in seconds
- Completely customizable control of specified sections of your LEDs 
- 38 color options as well as brightness control and custom color option.
- 10 modes with endless possibilities to let you create unique patterns for many circumstances. With more on the way
- Additional "Color Test" mode lets you play with colors to discover your robot's new favorite color.
